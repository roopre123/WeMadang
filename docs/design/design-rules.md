# 기본 디자인 규칙

> 모든 화면은 이 규칙을 따른다. 여기에 없는 값이 필요하면 Claude가 임의로 정하지 않고 먼저 물어본다.

## 화면 기준
화면은 두 종류로 나눈다.
- 조작 화면 (스트리머 브라우저, 방송에 송출하지 않음)
  - 일반 웹 화면. 높이는 고정하지 않음 (내용이 길면 스크롤)
  - 헤더, 푸터 있음 (`screens/common-frame.md`). 헤더 높이 64px
  - 본문 최대 폭 1200px, 가운데 정렬. 화면이 이보다 좁으면 좌우 여백 24px
  - 헤더, 푸터도 배경과 구분선은 화면 끝까지 채우고, 안의 내용(로고, 메뉴, 버튼, 글자)은 본문과 같은 1200px 폭 안에 넣는다 (본문과 세로줄이 맞게)
  - 이 폭은 `layout.css`의 공통 클래스 하나(예: `.container`)로 만들어 헤더, 본문, 푸터가 같이 쓴다
  - 더 넓게 써야 하는 화면은 화면 설명 파일에 따로 적는다
  - 반응형 (와이어프레임은 데스크톱 한 장만, 좁은 화면은 기본 규칙으로)
    | 너비 | 배치 |
    |---|---|
    | 1280 이상 (기준 너비 1920) | 와이어프레임 그대로 |
    | 768 ~ 1279 | 2단 → 1단으로 쌓기, 가로 카드는 한 줄에 1개, 버튼·글자 크기 그대로, 헤더는 한 줄 유지, 모달은 너비 90%까지 |
    | 768 미만 | 768 배치 그대로 (모바일 대응 안 함) |
- 표출 화면 (OBS 브라우저 소스, 방송에 송출)
  - 1920×1080 고정, 스크롤 없음
  - 버튼, 마우스 올림 효과 없음 (보여주기만)
  - 방송을 작게 보는 시청자도 읽을 수 있게 글자를 크게
  - 헤더, 푸터 없음
  - 배치 규칙은 아래 "표출 화면 공통"

## 표출 화면 공통
모든 송출 화면(게임 목록, 게임 첫 화면, 게임별 화면)이 같이 쓰는 규칙. 화면이 바뀌어도 로고와 안내 위치가 그대로 보이게.

- 배경 : **꽉 채움** (`background` 색). OBS 맨 아래에 깔고, 스트리머의 캠·채팅창은 그 위에 올라감
- 가장자리 여백 : 화면의 5% (좌우 96, 위아래 54). 이 안에 글자를 두지 않음
- **내용 영역 : 가운데 1200** (가로 360 ~ 1560), 세로 102 ~ 978 (가장자리 54 + 48)
  - 양옆 360은 캠·채팅 자리로 비워둠. 중요한 정보(제목, 타일, 투표 막대)는 항상 내용 영역 안에
- 로고 : 내용 영역 왼쪽 위. 로고 56 + "위마당" (40px / 굵게)
- 아래 안내 : 내용 영역 왼쪽 아래 아이콘 `message-circle` 24 + "치지직 채팅으로 참여해요" (24px, `text-sub`)
- 가장 작은 글자 24px (아래 "글꼴" 표의 표출 화면 열)
- 방송 패널 미리보기(576×324, 0.3배)로 줄여도 읽혀야 함
- 투명 배경은 나중에 요청이 있으면 송출 URL 옵션(예: `?bg=none`)으로 추가
- 송출 화면 종류 : 게임 목록(`screens/overlay-game-select.md`), 게임 첫 화면(`screens/overlay-game-ready.md`), 게임별 화면(게임 만들 때). 대기·준비 중 화면은 따로 없음

## 테마
- 라이트 / 다크 두 벌을 만든다
- 브라우저(OS) 설정을 자동으로 따라간다 (`prefers-color-scheme`)
- 모든 색은 `variables.css`의 변수로만 사용한다 (화면 코드에 색 코드 직접 쓰지 않기)

## 포인트 브릿지 (그라데이션) — 브랜드 전용
- 라이트 / 다크 같은 값
- `linear-gradient(90deg, #FF7EB6 0%, #7EC8FF 50%, #B5E655 100%)` (핑크 → 하늘 → 연두, 같은 간격)
- 사용하는 곳은 이 세 군데뿐
  - 로고 (`src/assets/logo.svg`에 이미 들어 있음)
  - 현재 메뉴 밑줄 (2px)
  - 진행 바 (카운트다운, 남은 시간 등)
- 버튼, 글자, 선택 표시에는 쓰지 않는다. 그런 곳은 포인트 민트(`primary`, `accent`)를 쓴다

## 포인트 민트
- 브랜드 그라데이션 대신 화면에서 쓰는 단색 포인트
- 팀 색(파랑/빨강)과 겹치지 않는 색이라 투표·토론 화면에서도 헷갈리지 않는다
- 쓰는 곳: 주요 버튼, 선택된 항목
- 많이 쓰면 촌스러워지므로 한 화면에 2~3군데까지

## 강조 글자 (accent)
- 초록. 제목 속 한 단어, 강조 숫자 같은 **큰 글씨(20px 이상, 굵게)**에만 쓴다 (라이트 모드 초록은 작은 글자에서 읽기 어렵다)
- 링크, 작은 안내 글자에는 쓰지 않는다
- 버튼, 배경, 넓은 면적에는 쓰지 않는다 (치지직 공식 서비스처럼 보이지 않게. 치지직 약관의 제휴 오인 금지)
- 한 화면에 1~2군데까지

## 로고
- 파일: `frontend/src/assets/logo.svg` (정사각형, 그라데이션 + W 모양)
- 파비콘: `frontend/public/favicon.svg` (같은 그림)
- 헤더: 로고 28px + "위마당" 글자(일반 `text` 색, 굵게). 글자에는 그라데이션을 넣지 않는다
- 푸터: 로고 24px
- 로고 그림은 라이트/다크 같은 파일을 쓴다 (안쪽 W가 진한 색이라 양쪽 다 보임)
- 로고 모양, 색을 바꾸거나 늘리지 않는다 (가로세로 비율 유지)

## 아이콘 (공통)
- 화면에 쓰는 아이콘은 전부 **Tabler Icons** (MIT, 선 모양)로 통일. Vue에서는 `@tabler/icons-vue` 패키지
- 그림 파일(svg, png)을 따로 넣지 않음
- 색 : 글자색을 따라감 (라이트/다크 자동). 따로 색을 정하지 않음
- 선 두께 : 기본값 2
- 크기
  | 쓰는 곳 | 크기 |
  |---|---|
  | 버튼 안 (페이지 번호 화살표, 접기, 검색칸) | 16 |
  | 헤더 알림 | 20 |
  | 방송 패널 퀵메뉴 버튼 | 24 |
  | 에러 화면 | 48 |
- 쓰는 아이콘
  | 쓰는 곳 | Tabler 이름 |
  |---|---|
  | 헤더 알림 켜짐 / 꺼짐 | `bell` / `bell-off` |
  | 검색칸 안 | `search` |
  | 페이지 맨 앞 / 이전 / 다음 / 맨 뒤 | `chevrons-left` / `chevron-left` / `chevron-right` / `chevrons-right` |
  | 방송 패널 [미리보기 접기] | `chevron-right` |
  | 퀵메뉴 버튼 : 방송 / 펼치기 | `broadcast` / `chevron-left` |
  | 송출 화면 "치지직 채팅으로 참여해요" 앞 | `message-circle` |
  | 게임 화면 [게임 목록으로] | `arrow-left` |
  | 에러 화면 : 없는 주소 / 없는 게임 / 불러오기 실패 | `map-question` / `mood-empty` / `cloud-off` |
- 연결 상태 점(●)은 아이콘이 아니라 동그라미 도형 (8px)
- 숫자, 버튼 글자는 아이콘이 아니라 글자

## 게임 아이콘
- 게임(퀴즈는 주제)마다 아이콘 하나 + 색 하나. 게임 목록 카드, 송출 화면 타일, 게임 첫 화면에 같이 씀
- 아이콘 : 무료 아이콘 모음 Tabler Icons (MIT, 선 모양)에서 이름으로 고름. games 테이블 `icon` 칸에 이름 저장 (예: `scale`, `messages`, `flag`, `music`)
  - 직접 그린 그림이나 게임·애니 공식 그림은 쓰지 않음 (저작권)
- 모양 : 정사각형 색 상자 안에 아이콘. 상자 모서리는 크기의 20% 정도
- 크기
  | 쓰는 곳 | 상자 | 안의 아이콘 |
  |---|---|---|
  | 게임 목록 카드 (조작 화면) | 40 | 24 |
  | 송출 화면 게임 목록 타일 | 72 | 40 |
  | 송출 화면 게임 첫 화면 | 96 | 56 |
- 색 : 아래 6가지 중 하나. games 테이블 `color` 칸에 이름 저장. 파랑·빨강은 팀 색과 헷갈려서 쓰지 않음
  | 이름 | 라이트 배경 / 아이콘 | 다크 배경 / 아이콘 |
  |---|---|---|
  | purple | #CECBF6 / #3C3489 | #3C3489 / #CECBF6 |
  | amber | #FAC775 / #633806 | #633806 / #FAC775 |
  | teal | #9FE1CB / #085041 | #085041 / #9FE1CB |
  | pink | #F4C0D1 / #72243E | #72243E / #F4C0D1 |
  | green | #C0DD97 / #27500A | #27500A / #C0DD97 |
  | gray | #D3D1C7 / #444441 | #444441 / #D3D1C7 |
  - 라이트 배경은 한 단계 진한 색 (11/21 변경). 연한 색은 회색 카드(`surface`) 위에서 흐려 보였음
  - `variables.css`에 `--icon-{이름}-bg`, `--icon-{이름}-fg` 변수로 넣어서 씀
- 쓸 수 있는 아이콘 : **Tabler 아이콘 이름이면 무엇이든** (https://tabler.io/icons 에서 찾은 이름 그대로)
  - `GameIcon.vue`가 이름으로 그때그때 불러옴 (필요한 것만 불러와서 앱이 무거워지지 않음). 새 퀴즈를 만들어도 소스 수정 없음
  - 이름이 비었거나 틀리면 분류 기본 아이콘 + gray
  - 불러오는 동안은 빈 색 상자
- 아이콘이 없는 게임 : 분류 기본 아이콘 (퀴즈형 `question-mark`, 토론형 `scale`, 면담형 `messages`), 색 gray

## 선택 표시
- 선택된 항목 (예: 토론 시간 3분 / 5분 / 7분 중 하나): `primary` 배경 + `on-primary` 글자 + 굵게
- 선택 안 된 항목: 배경 없음 + `border` 테두리 + `text-sub` 글자
- 현재 메뉴: `text` 색 + 굵게 + 브릿지 밑줄. 나머지 메뉴는 `text-sub`

## 글꼴
- 따로 웹폰트를 불러오지 않고 각 컴퓨터의 기본 글꼴을 쓴다 (설치·로딩 없음)
  - `font-family: -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Malgun Gothic", "맑은 고딕", sans-serif;`
  - 맥은 애플 SD 고딕 네오, 윈도우는 맑은 고딕으로 보인다
- 굵기: 보통 400, 굵게 700 두 가지만
- 줄 간격: 본문 1.6, 제목 1.3

| 단계 | 조작 화면 | 표출 화면 (1920×1080) | 쓰는 곳 |
|---|---|---|---|
| 큰 제목 | 40px / 굵게 | 72px / 굵게 | 시작 화면 문구, 투표 주제 |
| 제목 | 28px / 굵게 | 48px / 굵게 | 화면·모달 제목, 결과 숫자 |
| 소제목 | 20px / 굵게 | 36px / 굵게 | 영역 제목, 팀 이름 |
| 본문 | 16px | 32px | 일반 글, 말풍선 |
| 작은 글자 | 14px | 24px | 보조 설명, 라벨, 푸터 |

- 표출 화면은 방송을 작게 보는 시청자를 위해 조작 화면보다 크게, 가장 작은 글자도 24px
- 카운트다운 숫자처럼 특별히 큰 글자는 화면 설명 파일에 따로 적는다

## 간격, 모서리
- 간격 단계: 4 / 8 / 16 / 24 / 32 / 48 / 64px (이 값 안에서만 쓴다)
- 모서리: 버튼·입력칸 8px, 카드·모달 12px, 말풍선 16px
- 그림자: 모달에만 약하게 (나머지는 테두리로 구분)

## 버튼
조작 화면 전용 (표출 화면에는 버튼 없음). 방송 중에 빨리 누르는 걸 고려해서 일반 사이트보다 한 단계 크게.

- 모서리: 8px
- 버튼 사이 간격: 8px

| 크기 | 높이 | 글자 | 좌우 여백 | 쓰는 곳 |
|---|---|---|---|---|
| 큰 버튼 | 48px | 16px | 24px | 진행 버튼 (투표 시작, 토론 시작 등) |
| 기본 버튼 | 40px | 15px | 20px | 대부분 (취소, 저장, 다시 측정 등) |
| 작은 버튼 | 32px | 13px | 12px | 헤더, 복사, +30초 같은 보조 |

| 모양 | 생김새 | 쓰는 곳 |
|---|---|---|
| 주요 | `primary`(민트) 배경 + `on-primary` 글자 | 한 화면에 하나 (투표 시작 등) |
| 보조 | `surface` 배경 + `border` 테두리 + `text` 글자 | 취소, 다시 측정 등 |
| 위험 | 배경 없음 + `error` 테두리와 글자 | 벤, 즉시 종료 |

- 상태
  - 마우스 올림: 살짝 진하게
  - 눌림: 98% 크기로 살짝 작아짐
  - 비활성: 40% 흐리게 + 금지 커서
