# 시작 화면

- 파일: `src/views/StartView.vue`
- 와이어프레임: `../wireframes/start.png` (데스크톱. 좁은 화면은 design-rules.md 반응형 규칙)
- 종류: 조작 화면 (일반 웹 화면, 방송에 송출하지 않음)
- 헤더, 푸터: `common-frame.md` 공통 프레임 사용. 이 문서는 본문만 다룸

## 목적
위마당을 소개하고, 로그인하거나 게임 목록으로 가는 첫 화면

## 요소 (와이어프레임 기준)
- 왼쪽: 토론 화면 예시 (이미지 또는 움직이는 이미지 자리)
- 오른쪽:
  - 위마당 문구 소개
  - 소개 문구
  - [로그인] [게임 목록] 버튼
  - 방문 카운트
  - 게임 플레이 카운트
  - 참여 시청자 누적 카운트
- 아래 (구분선 아래): 기능 소개 (나중에 채움, 지금은 자리만)

## 상태
- 기본 하나뿐
- 로그인 성공·실패는 공통 토스트로 보여주므로 이 화면에서 따로 그리지 않음
- 카운트는 지금은 0으로 표시

## 동작 (emit)
| 동작 | emit |
|---|---|
| [치지직으로 로그인] 클릭 | `login` |
| [게임 둘러보기] 클릭 | `show-games` |

## props
| 이름 | 타입 | 설명 |
|---|---|---|
| visitCount | number | 방문 카운트 |
| playCount | number | 게임 플레이 카운트 |
| viewerCount | number | 참여 시청자 누적 카운트 |

## 문구 (와이어프레임 기준)
- 위마당 문구 소개: 판을 열면, 채팅이 모인다
- 소개 문구: 시청자는 치지직 채팅만 치면 돼요. 투표하고, 편 나눠 토론하고, 결과까지 방송 화면에 바로 보여줘요.
- 버튼: 치지직으로 로그인 / 게임 둘러보기
- 카운트 이름: 방문 / 게임 플레이 / 참여 시청자 (참여 시청자는 뒤에 "명")
- 토론 화면 예시 아래 글씨: 밸런스 토론 진행 화면
- 기능 소개 제목: 기능 소개 (카드 3칸, 내용은 나중에 채움)

## 깨지기 쉬운 경우
- 카운트가 아주 큰 숫자일 때 (예: 23,456,789) → 쉼표 표시
- 토론 화면 예시 이미지가 아직 없을 때 (빈 자리 표시)
- 좁은 너비 (768 ~ 1279)에서 1단으로 쌓였을 때
