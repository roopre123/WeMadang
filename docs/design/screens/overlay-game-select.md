# 송출 화면 : 게임 목록

- 파일: `src/components/overlay/OverlayGameSelect.vue` (표출 페이지 `/overlay/{키}` 안에서 서버 상태가 "게임 목록"일 때 보여주는 화면)
- 와이어프레임: `../wireframes/overlay-game-select.png`
- 종류: 표출 화면 (OBS 브라우저 소스, 방송에 송출). design-rules.md "표출 화면 공통" 따름
- **크기·간격은 와이어프레임 픽셀이 아니라 이 문서 기준.** 와이어프레임의 회색 양옆은 캠·채팅 자리를 보여주는 예시

## 목적
스트리머가 게임 목록에서 고르는 동안, 시청자에게 **스트리머와 같은 페이지**를 보여줌

## 스트리머 화면과 맞추는 것
- 같은 분류, 같은 검색어(Enter로 확정된 것만), 같은 페이지, 같은 9개
- 스트리머 화면의 스크롤은 따라가지 않음 (송출 화면은 스크롤 없음)
- 바뀌는 때는 스트리머가 분류 버튼, 검색 Enter, 페이지 번호를 눌렀을 때뿐

## 배치 (1920×1080)
- 내용 영역 : 가로 360 ~ 1560 (폭 1200), 세로 102 ~ 978
- 세로 간격 : 로고 → 제목 24, 제목 → 분류 24, 분류 → 타일 32. 맨 아래 줄은 978에 붙임
- 크기는 조작 화면의 1.5배 (간격 단계에 맞춤)
  - 분류 표시 : 높이 48, 좌우 24, 사이 16, 모서리 8
  - 알약(분류 표시) : 좌우 16, 모서리 999
  - 타일 안 : 아이콘 ↔ 글자 24, 알약 ↔ 이름 8
  - 페이지 번호 칸 : 사이 8, 모서리 8, 지금 페이지 `primary` 배경
  - 채팅 안내 아이콘 ↔ 글자 8
- 위에서부터
  1. 왼쪽 위 : 로고 56 + "위마당" (40px / 굵게)
  2. 가운데 : 제목 "게임을 고르고 있어요" (제목 48px / 굵게)
  3. 가운데 : 지금 분류 표시 [전체][퀴즈형][토론형][면담형]. 지금 분류만 선택 표시. 누를 수 없음 (보여주기만). 글자 24px
  4. 게임 타일 3열 × 3줄 = 9개
  5. 맨 아래 한 줄 : 왼쪽 아이콘 `message-circle` 24 + "치지직 채팅으로 참여해요" (24px, `text-sub`), 오른쪽 페이지 번호

### 게임 타일
- 폭 384 (3열, 사이 24), 높이 160, `surface` 배경, 모서리 16, 안쪽 여백 24
- 왼쪽 : 게임 아이콘 72×72 (design-rules.md "게임 아이콘")
- 오른쪽 위아래로
  - 분류 표시 : 둥근 알약 테두리, 24px, `text-sub`
  - 게임 이름 : 36px / 굵게. 길면 한 줄 `...`
- 설명, [시작하기] 버튼은 넣지 않음 (시청자가 작게 보므로 이름만 크게)

### 페이지 번호
- 스트리머 화면과 같은 숫자 칸 (최대 5개, 지금 페이지 선택 표시). 칸 48×48, 글자 24px
- 없는 페이지 칸은 그리지 않음. 페이지가 1개면 숨김
- 화살표 [<<][<][>][>>]는 넣지 않음 (누를 수 없으니까)

## 상태
- 기본 / 검색 결과 없음 ("찾는 게임이 없어요." 36px 보통 굵기, 타일 자리 가운데) / 마지막 페이지 9개 미만

## props
| 이름 | 타입 | 설명 |
|---|---|---|
| games | Game[] | 지금 페이지의 게임 (최대 9개). game-select.md와 같은 모양 |
| category | string | 지금 분류 |
| page | number | 지금 페이지 |
| totalPages | number | 전체 페이지 |

## 문구

- 아래 안내 : 치지직 채팅으로 참여해요
