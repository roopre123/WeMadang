# 공통 프레임 (헤더, 푸터, 토스트, 모달)

- 파일: `src/components/AppHeader.vue`, `src/components/AppFooter.vue`, `src/components/AppToast.vue`, `src/components/AppModal.vue`
- 와이어프레임: `../wireframes/common-frame.png`
  - 위에서부터 로그인 전 헤더 / 로그인 후 헤더 / 푸터 순서
  - 알림 아이콘은 켜짐(위), 꺼짐(아래) 두 상태를 같이 그림
  - 로그인 후 헤더의 딜레이 값은 미설정(위), 설정됨(아래) 두 상태를 같이 그림
- 조작 화면(일반 웹 화면)에서만 사용. 표출 화면(OBS)에는 헤더, 푸터 없음

## 배치
- 헤더: 화면을 스크롤해도 위에 고정, 높이 64px
- 본문
- 푸터: 화면에 고정하지 않고 본문 아래에 붙음

## 헤더 (로그인 전)
- 왼쪽: (로고) 위마당
- 가운데: 게임 목록, 커뮤니티
- 오른쪽: [알림켜기 / 알림끄기 아이콘] [로그인]

## 헤더 (로그인 후)
- 왼쪽: (로고) 위마당
- 가운데: 게임 목록, 커뮤니티
- 오른쪽: [딜레이 보정] 딜레이 값 · [알림켜기 / 알림끄기 아이콘] · "닉네임님 안녕하세요." · [로그아웃]
- 딜레이 값: 저장 전 `딜레이 미설정`, 저장 후 `딜레이 3.2초`
- 닉네임은 치지직 닉네임

## 헤더 공통
- 로고: `src/assets/logo.svg` 28px + "위마당" (일반 글자색, 굵게). design-rules.md "로고" 참고
- 헤더 배경과 아래 구분선은 화면 끝까지, 안의 내용은 본문과 같은 1200px 폭 안에 (design-rules.md "화면 기준")
- 화면이 1200px보다 좁으면 좌우 여백 24px (로고, 로그아웃이 화면 끝에 붙지 않게)
- 닉네임이 길면 한 줄로 자르고 `...` 표시 (헤더가 화면 밖으로 넘치지 않게, 최대 너비 160px 정도)
- 현재 보고 있는 메뉴 강조 (`text` 색 + 굵게 + 포인트 브릿지 밑줄, design-rules.md "선택 표시" 참고)
- 알림 버튼은 불필요하면 나중에 삭제 가능
- 좁은 너비는 design-rules.md 반응형 규칙
- **넓게 보기**가 적용된 화면에서는 헤더 안쪽 폭도 본문과 같은 **1776** (design-rules.md "화면 기준"). 적용 여부는 부모(App)가 `wide`로 알려줌. 넓게 보기가 없는 화면으로 가면 다시 1200 (헤더 양 끝이 움직이는 건 받아들임)

## 푸터
- 푸터 배경과 위 구분선은 화면 끝까지, 안의 내용은 본문과 같은 1200px 폭 안에
- 왼쪽: (로고 24px) 위마당은 치지직, 네이버와 제휴하지 않습니다.
- 오른쪽: [이용약관] [개인정보처리방침] ©2026 wemadang
- 넓게 보기가 적용된 화면에서는 안쪽 폭 1776 (헤더와 같음)

## 토스트
- 잠깐 떴다 사라지는 안내 (로그인 성공·실패, 로그아웃 성공·실패, 알림, 저장 완료)
- 앞에 작은 점으로 종류 구분: 성공(success 색) / 오류(error 색)
- 위치: 화면 하단 가운데, 2~3초 뒤 사라짐

## 모달
- 사용자가 작업해야 하는 기능 (딜레이 보정 등)
- 뒤 배경을 살짝 흐리게(어둡게)

## 동작 (emit)
| 동작 | emit |
|---|---|
| 로그인 클릭 | `login` |
| 로그아웃 클릭 | `logout` |
| 알림 on/off 클릭 | `toggle-sound` |
| 딜레이 보정 클릭 | `open-delay` |
| 메뉴 클릭 | `navigate` (메뉴 이름 전달) |
| 모달 닫기 | `close` |

## props
| 컴포넌트 | 이름 | 타입 | 설명 |
|---|---|---|---|
| AppHeader | loggedIn | boolean | 로그인 여부 |
| AppHeader | nickname | string | 치지직 닉네임 |
| AppHeader | soundOn | boolean | 알림 켜짐 여부 |
| AppHeader | activeMenu | string | 강조할 메뉴 |
| AppHeader | wide | boolean | 넓게 보기 적용 여부 (true면 안쪽 폭 1776) |
| AppFooter | wide | boolean | 넓게 보기 적용 여부 (true면 안쪽 폭 1776) |
| AppToast | message | string | 안내 문구 |
| AppToast | type | 'success' \| 'error' | 종류 |
| AppModal | open | boolean | 열림 여부 |

## 깨지기 쉬운 경우
- 긴 닉네임
- 라이트 / 다크 모드 둘 다
- 좁은 너비 (768 ~ 1279)에서 헤더 오른쪽이 넘칠 때
