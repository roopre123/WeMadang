# 공통 에러 화면 (스프린트 3)

- 파일: `src/views/ErrorView.vue`
- 와이어프레임: `../wireframes/error.png` (위 : 로그인 후 모양, 아래 작은 그림 : 다른 에러 종류 예시)
- 종류: 조작 화면 (일반 웹 화면, 방송에 송출하지 않음)
- 헤더, 푸터: `common-frame.md` 공통 프레임 사용
- 방송 패널: `broadcast-panel.md` (로그인 후에만, 접기 없음)
- **송출 화면에는 영향 없음.** 에러가 나도 직전 송출 화면이 그대로 나감 (송출용 에러 화면은 없음)
- **크기·간격은 와이어프레임 픽셀이 아니라 이 문서와 design-rules.md 기준**

## 목적
찾는 페이지나 게임이 없거나 게임 정보를 불러오지 못했을 때 알려주고, 갈 곳을 버튼으로 주는 화면. 화면 하나를 종류(type)만 바꿔서 씀

## 종류
| type | 언제 | 아이콘 | 제목 | 설명 | 버튼 |
|---|---|---|---|---|---|
| `not-found-page` | 없는 주소 | `map-question` | 페이지를 찾을 수 없어요 | 주소를 다시 확인해 주세요. | [홈으로] |
| `not-found-game` | 없는 게임·숨긴 게임 (서버 404), 연결표에 없는 screen | `mood-empty` | 게임을 찾을 수 없어요 | 주소가 바뀌었거나 지금은 열 수 없는 게임이에요. | [게임 목록으로] |
| `load-failed` | 서버·네트워크 오류 (404 말고) | `cloud-off` | 게임 정보를 불러오지 못했어요 | 잠시 후 다시 시도해 주세요. | [다시 시도] [게임 목록으로] |

## 배치

### 로그인 후
- 본문 1200을 왼쪽 568 / 간격 24 / 오른쪽 608로 나눔 (`game-play.md`와 같은 틀)
- 왼쪽 568 : 에러 내용 묶음을 가로 가운데, 위 여백 120
- 오른쪽 : 방송 패널 (접기 없음). 위쪽은 본문 위 여백 48에 맞춤. 미리보기 칸은 슬롯 `preview`, 비어 있으면 검은 상자 (`broadcast-panel.md`)

### 로그인 전
- 방송 패널 없음. 본문 1200 가로 가운데에 에러 내용 묶음만, 위 여백 120

## 요소 (에러 내용 묶음, 위에서부터 가운데 정렬)
1. 아이콘 48 (Tabler, 선 모양), `text-sub` 색, **배경 상자 없음**
2. 제목 : 소제목 (20px / 굵게). 아이콘과 사이 16
3. 설명 : 14px, `text-sub`. 제목과 사이 8
4. 버튼 줄 : 기본 버튼, 버튼 사이 8. 설명과 사이 24
   - 버튼이 하나면 보조 모양
   - 버튼이 둘이면 [다시 시도]는 주요(민트), [게임 목록으로]는 보조

## 상태
- 종류 3가지 × 로그인 전 / 로그인 후

## 동작 (emit)
| 동작 | emit |
|---|---|
| [홈으로] 클릭 | `go-home` |
| [게임 목록으로] 클릭 | `go-games` |
| [다시 시도] 클릭 | `retry` |
| 방송 패널 [복사] | `copy-url` |

- 이동과 다시 불러오기는 부모가 처리

## props
| 이름 | 타입 | 설명 |
|---|---|---|
| type | 'not-found-page' \| 'not-found-game' \| 'load-failed' | 에러 종류 |
| loggedIn | boolean | 로그인 여부 (방송 패널 표시) |
| overlayUrl | string | 표출 URL (방송 패널로 넘김) |
| connected | boolean | OBS 연결 여부 (방송 패널로 넘김) |

- 슬롯 `preview` : 방송 패널 미리보기 칸 (지금은 비워둠. "송출 상태 자동 전환" 이후 지금 나가는 송출 화면)

## 문구
- 위 "종류" 표 그대로

## 나중에
- [다시 시도]를 누른 뒤 응답을 기다리는 동안 버튼에 불러오는 중 표시

## 깨지기 쉬운 경우

- 화면 높이가 낮을 때
- 라이트 / 다크 모드
