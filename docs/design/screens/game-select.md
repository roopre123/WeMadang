# 게임 목록 화면 (스프린트 2)

- 파일: `src/views/GameSelectView.vue`
- 와이어프레임
  - `../wireframes/game-select-guest.png` : 로그인 전 (방송 패널 접었을 때도 같은 모양)
  - `../wireframes/game-select-login.png` : 로그인 후, 방송 패널 펼침 + 접었을 때의 퀵메뉴 버튼
- 종류: 조작 화면 (일반 웹 화면, 방송에 송출하지 않음)
- 헤더, 푸터: `common-frame.md` 공통 프레임 사용
- 방송 패널: `broadcast-panel.md` (로그인 후에만)
- 이 화면에 있을 때 표출 화면(OBS)에는 `overlay-game-select.md` 화면이 나감
- **크기·간격은 와이어프레임 픽셀이 아니라 이 문서와 design-rules.md 기준.** 와이어프레임은 구성만 본다

## 목적
진행할 게임을 고르는 화면. 로그인 없이도 볼 수 있음

## 배치

### 로그인 전 / 로그인 후 방송 패널 접힘 (같은 모양)
- 본문 1200 전체 사용
- 위에서부터
  1. 제목 "게임 목록" + 아래 안내 문구
  2. 한 줄 : 왼쪽 분류 버튼 [전체][퀴즈형][토론형][면담형] → 사이 32 → 정렬 [기본순|인기순], 오른쪽 끝 검색칸 (정렬은 와이어프레임에는 없음, 이 문서 기준)
  3. 게임 카드 3열 × 3줄 = 9개
  4. 페이지 번호 (가운데)
- 로그인 후 접힘일 때만 : 본문 바깥 오른쪽 여백에 방송 패널 퀵메뉴 버튼 (`broadcast-panel.md`)

### 로그인 후 방송 패널 펼침
- 본문 1200을 왼쪽 **568** / 간격 **24** / 오른쪽 **608**로 나눔
- 왼쪽 : 위 1~4와 같은 내용. 카드는 **2열 × 5줄 = 9개** (마지막 줄은 1개)
- 왼쪽 568에서는 분류 + 정렬 + 검색칸이 한 줄에 안 들어가서, 첫 줄 분류 + 정렬, 둘째 줄 검색칸(폭 568 전체). 두 줄 사이 16
- 오른쪽 : 방송 패널 (`broadcast-panel.md`). 스크롤해도 헤더 아래에 고정
- 9개가 화면보다 길어지면 **브라우저 스크롤** 사용 (목록 안에 따로 스크롤 만들지 않음)

| 상태 | 본문 폭 | 카드 열 | 카드 폭 |
|---|---|---|---|
| 로그인 전 / 패널 접힘 | 1200 | 3열 | 384 |
| 패널 펼침 | 568 | 2열 | 272 |

- 카드 사이 간격 : 가로 24, 세로 24
- 한 페이지는 상태와 상관없이 **항상 9개** (송출 화면과 같은 페이지를 보여주기 위해)

## 요소

### 제목
- "게임 목록" : 제목 (28px / 굵게)
- 안내 문구 : 본문 16px, `text-sub`
- 제목 위 여백 48, 제목 줄과 분류 줄 사이 24, 분류 줄과 카드 사이 32

### 분류 버튼
- [전체][퀴즈형][토론형][면담형], 기본은 [전체]
- 선택 표시 규칙 (design-rules.md "선택 표시"). 버튼 높이 32 (작은 버튼), 사이 8
- 누르면 그 분류만 보여주고 1페이지로 이동 (정렬과 검색어는 그대로 유지)

### 정렬
- [기본순|인기순] 두 칸이 붙은 버튼 묶음, 기본은 [기본순]
- 위치 : 분류 버튼 [면담형] 오른쪽, 분류 묶음과 사이 32 (분류 버튼 사이 8보다 넓게 띄워 분류와 구분). 분류 버튼과 같은 줄, 세로 가운데 맞춤
- 선택 표시 규칙 (design-rules.md "선택 표시"). 버튼 높이 32 (작은 버튼), 두 칸 사이 0 (붙어 있는 모양)
- 기본순 : 정해 둔 순서. 인기순 : 플레이가 많은 게임부터 (같으면 정해 둔 순서)
- 분류, 검색어와 같이 적용됨 (예: 퀴즈형 + 인기순 + "롤")
- 누르면 1페이지로 이동 (분류와 검색어는 그대로 유지)

### 검색칸
- 오른쪽 끝, 폭 280, 높이 40, 모서리 8
- 안내 글자 : "게임 이름으로 검색"
- 칸 안 왼쪽에 아이콘 `search` 16 (design-rules.md "아이콘 (공통)")
- **Enter를 눌렀을 때 검색** (글자 칠 때마다 검색하지 않음. 송출 화면이 깜빡이지 않게)
- 이름 일부만 맞아도 찾음. 검색하면 1페이지로 이동

### 게임 카드
- `surface` 배경, 모서리 12, 안쪽 여백 24
- 첫 줄 : 게임 아이콘 40×40 (design-rules.md "게임 아이콘") + 오른쪽에 위아래로
  - 분류 표시 : 둥근 알약 모양 테두리 (모서리 999, `border` 테두리, `text-sub` 14px, 좌우 여백 10)
  - 게임 이름 : 소제목 (20px / 굵게). 길면 한 줄에서 `...`
- 둘째 줄 : 설명 (14px, `text-sub`). 최대 2줄, 넘으면 `...`
- 오른쪽 아래 : [시작하기] 작은 버튼 (보조 모양. 카드가 9개라 주요(민트) 버튼을 쓰지 않음)
- 카드 높이는 같은 줄끼리 맞춤

### 페이지 번호
- 카드 아래 48 띄우고 가운데, 페이지 번호 아래도 48 (펼침이면 왼쪽 568 영역의 가운데)
- `[<<] [<] [1] [2] [3] [4] [5] [>] [>>]`
  - 각 칸 32×32, 사이 8, 작은 버튼 모양
  - 화살표는 아이콘 16 : [<<] `chevrons-left`, [<] `chevron-left`, [>] `chevron-right`, [>>] `chevrons-right`. 숫자는 글자
  - 숫자는 최대 5개, 지금 페이지가 가운데 오게 이동 (예: 7페이지면 5 6 [7] 8 9)
  - 지금 페이지는 선택 표시 (`primary` 배경)
  - **없는 페이지 칸은 그리지 않음** (페이지가 3개면 1 2 3만)
  - 첫 페이지에서 [<<][<], 마지막 페이지에서 [>][>>]는 비활성
- 페이지가 1개면 페이지 번호 줄 자체를 숨김

### 검색 결과 없음
- 카드 자리에 가운데 정렬
  - "찾는 게임이 없어요." (본문 16px)
  - "다른 이름으로 검색해 보세요." (14px, `text-sub`)
- 최소 높이 200

## 상태
- 로그인 전 / 로그인 후 패널 펼침 / 로그인 후 패널 접힘
- 검색 결과 없음
- 페이지 1개 (페이지 번호 숨김)

## 동작 (emit)
| 동작 | emit |
|---|---|
| [시작하기] 클릭 | `select-game` (게임 id) |
| 분류 버튼 클릭 | `change-category` ('' \| 'quiz' \| 'debate' \| 'interview') |
| 정렬 버튼 클릭 | `change-sort` ('default' \| 'popular') |
| 검색칸에서 Enter | `search` (검색어) |
| 페이지 번호 클릭 | `change-page` (페이지 번호) |
| 방송 패널 접기 / 펼치기 | `toggle-panel` |
| 방송 패널 [복사] | `copy-url` |

- 로그인 안 한 상태에서 [시작하기]를 누르면 로그인으로 보냄 (부모가 처리)
- 방송 패널의 동작은 `broadcast-panel.md`

## props
| 이름 | 타입 | 설명 |
|---|---|---|
| games | Game[] | 지금 페이지의 게임 (최대 9개) |
| category | string | 지금 분류 ('' = 전체) |
| sort | string | 지금 정렬 ('default' = 기본순, 'popular' = 인기순) |
| keyword | string | 지금 검색어 |
| page | number | 지금 페이지 (1부터) |
| totalPages | number | 전체 페이지 수 |
| loggedIn | boolean | 로그인 여부 (방송 패널 표시) |
| panelOpen | boolean | 방송 패널 펼침 여부 |
| overlayUrl | string | 표출 URL (방송 패널로 넘김) |
| connected | boolean | OBS 연결 여부 (방송 패널로 넘김) |

- 슬롯 `preview` : 방송 패널 미리보기 칸에 넣을 송출 화면
- 화면 값('quiz', 'popular' 등)을 API 요청 값(QUIZ, POPULAR 등)으로 바꾸는 건 부모(화면 연결)가 함

Game : `{ id, name, description, category, screen, icon, color }`
- category : 'quiz' \| 'debate' \| 'interview' (화면 표시는 퀴즈형 / 토론형 / 면담형)
- icon : 아이콘 이름, color : 아이콘 색 이름 (design-rules.md "게임 아이콘")

## 문구
- 제목 : 게임 목록
- 안내 : 진행할 게임을 골라주세요.
- 검색칸 : 게임 이름으로 검색
- 검색 결과 없음 : 찾는 게임이 없어요. / 다른 이름으로 검색해 보세요.
- 게임 이름과 설명은 DB(games 테이블) 값. 와이어프레임의 "(텍스트 변경예정)"은 예시
  - 예시 데이터 : 밸런스 토론 "편 나눠 투표하고 토론해요." / 1:1 면담 (진실의 방) "시청자 한 명을 뽑아 대화해요." / 스무고개 "질문하며 정답을 좁혀요."

## 깨지기 쉬운 경우
- 긴 게임 이름 (예: 유튜브 랭킹 퀴즈 시즌2) : 한 줄 `...`
- 긴 설명 : 2줄 `...`
- 마지막 페이지의 카드가 9개보다 적을 때 (빈칸은 비워둠, 늘이지 않음)
- 페이지가 많을 때 (예: 12페이지) 번호 이동
- 패널을 펴고 접을 때 카드 열이 3 ↔ 2로 바뀜 (같은 9개, 같은 페이지 유지)
- 좁은 너비 (768 ~ 1279) : design-rules.md 반응형 규칙. 방송 패널은 카드 위로 쌓임
- 라이트 / 다크 모드
