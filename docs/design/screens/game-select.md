# 게임 목록 화면 (스프린트 2)

- 파일: `src/views/GameSelectView.vue`
- 와이어프레임: `../wireframes/game-select.png` (아직 없음)
- 종류: 조작 화면 (일반 웹 화면, 방송에 송출하지 않음)
- 헤더, 푸터: `common-frame.md` 공통 프레임 사용
- 이 화면에 있을 때 표출 화면(OBS)에는 대기 화면이 나감 (별도 문서로 정리 예정)

## 목적
진행할 게임을 고르는 화면. 로그인 없이도 볼 수 있음

## 요소
- 게임 목록 (지금은 밸런스 토론, 1:1 면담)
- 로그인 후에만 보이는 것: 표출 URL 복사
- 그 밖의 요소는 와이어프레임 그릴 때 정함

## 참고
- 딜레이 보정은 이 화면이 아니라 헤더의 [딜레이 보정] 버튼 → 모달에서 진행

## 동작 (emit)
| 동작 | emit |
|---|---|
| 게임 선택 | `select-game` (게임 id 전달) |

## props
| 이름 | 타입 | 설명 |
|---|---|---|
| games | array | 게임 목록 (id, 이름, 설명) |
| loggedIn | boolean | 로그인 여부 |
