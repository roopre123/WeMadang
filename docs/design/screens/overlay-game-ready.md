# 송출 화면 : 게임 첫 화면 (준비 중)

- 파일: `src/components/overlay/OverlayGameReady.vue` (표출 페이지 안에서 서버 상태가 "게임 첫 화면"일 때)
- 와이어프레임: `../wireframes/overlay-game-ready.png`
- 종류: 표출 화면. design-rules.md "표출 화면 공통" 따름
- **크기·간격은 와이어프레임 픽셀이 아니라 이 문서 기준**

## 목적
스트리머가 게임 목록에서 게임에 들어가 설정하는 동안, 시청자에게 어떤 게임이 시작될지 알려줌. **모든 게임이 같은 화면**을 쓰고 게임 정보만 바뀜

## 언제 나오나
- 스트리머가 게임 목록에서 게임을 고르면 자동으로 이 화면
- 스트리머가 게임 안에서 [시작하기]를 누르면 그 게임의 다음 송출 화면으로
- 스트리머가 목록으로 돌아가면 `overlay-game-select`로

## 배치 (1920×1080)
- 내용 영역 : 가로 360 ~ 1560, 세로 102 ~ 978
- 왼쪽 위 : 로고 56 + "위마당" (40px / 굵게)
- 가운데 (가로·세로 모두 가운데 정렬)
  - 한 줄 : 게임 아이콘 96×96 + 사이 24 + 게임 이름 (큰 제목 72px / 굵게)
  - 아래 32 띄우고 안내 두 줄 (소제목 36px, `text-sub`, 가운데 정렬)
- 왼쪽 아래 : 아이콘 `message-circle` 24 + "치지직 채팅으로 참여해요" (24px, `text-sub`)

## props
| 이름 | 타입 | 설명 |
|---|---|---|
| game | Game | 고른 게임 (이름, 아이콘, 색). game-select.md와 같은 모양 |

## 문구
- 게임 이름 : DB 값 (와이어프레임의 "(변수사용할거임)")
- 안내 : 게임을 준비 중이에요. / 잠시만 기다려주세요.
- 아래 안내 : 치지직 채팅으로 참여해요
