# 로그인 확인 모달

- 파일: `src/components/LoginConfirmModal.vue` (공통 프레임의 AppModal 안에 들어감)
- 와이어프레임: 없음. `delay.md`의 #1 안내 모달과 같은 모양 (제목 / 문구 / 버튼 두 개)
- 종류: 조작 화면 모달 (방송에 송출하지 않음)

## 목적
치지직 계정으로 로그인한다는 것을 로그인 전에 분명히 알려준다.
치지직에 이미 로그인된 사람은 치지직 화면 없이 바로 돌아오므로, 이 안내가 없으면 로그인된 줄 모를 수 있다.

## 열리는 때
- 헤더 [로그인] 클릭
- 시작 화면 [치지직으로 로그인] 클릭
- 로그인 안 한 상태에서 게임 목록 [시작하기] 클릭
- (여는 것은 부모가 처리. 이 컴포넌트는 내용만 그린다)

## 요소
- 제목
- 안내 문구
- 버튼: [취소] [확인] (오른쪽 정렬, [확인]이 주 버튼)

## 문구
- 제목: 치지직 로그인
- 안내 문구: 치지직 계정과 연동하여 로그인합니다.
- 버튼: 취소 / 확인

## 동작 (emit)
| 동작 | emit |
|---|---|
| [취소] | `cancel` |
| [확인] | `confirm` |

- 뒤 배경 클릭, X 버튼은 AppModal의 `close`가 처리 (부모가 [취소]와 같게 처리)
