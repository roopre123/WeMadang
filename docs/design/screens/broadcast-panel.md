# 방송 패널 (송출용 화면 미리보기)

- 파일: `src/components/BroadcastPanel.vue`
- 와이어프레임: `../wireframes/game-select-login.png` 오른쪽 (펼침) + 오른쪽 여백의 작은 버튼 (접힘)
- 종류: 조작 화면 공통 요소. **로그인 후에만** 보임
- 쓰는 곳: 게임 목록 화면, 게임 진행 화면
- **크기·간격은 와이어프레임 픽셀이 아니라 이 문서 기준**

## 목적
지금 시청자에게 나가는 송출 화면을 스트리머가 작게 보면서, OBS 연결 상태와 표출 URL을 확인하는 곳

## 펼침
- 폭 **608** (본문 1200 중 오른쪽. 왼쪽 568 / 간격 24)
- `surface` 배경, 모서리 12, 안쪽 여백 16
- 위에서부터
  1. 한 줄 : 왼쪽 "송출용 화면 미리보기" (소제목 20px / 굵게), 오른쪽 [미리보기 접기 >] 작은 보조 버튼 (글자 + 아이콘 `chevron-right` 16)
  2. 미리보기 **576×324** (송출 화면 1920×1080의 0.3배, 16:9), 모서리 8
     - 지금 나가는 송출 화면을 0.3배로 줄여서 그대로 보여줌 (게임 목록에서는 `overlay-game-select`)
     - 미리보기 칸은 슬롯. 게임 목록에서는 `OverlayGameSelect`를 `OverlayPreviewBox`로 0.3배 줄여 넣음 (분류·페이지가 같이 바뀜)
     - 슬롯이 비어 있으면 검은 상자
  3. 연결 상태 한 줄 : 점(8px) + 글자 14px. **상태에 따라 하나만** 보임
     - ● OBS 연결됨 (`success` 점)
     - ● OBS 연결 안 됨 (`error` 점)
  4. 한 줄 : 표출 URL 칸(읽기 전용, 높이 40, 점선 테두리, 길면 `...`) + [복사] 작은 버튼
  5. 안내 : "로그인할 때마다 주소가 바뀌어요. 방송 전에 OBS 브라우저 소스에 넣어주세요." (14px, `text-sub`)
     - 표출 URL은 로그인할 때마다 새로 만들어짐 (치지직 정보를 서버에 저장하지 않기 때문). 로그인한 동안은 게임·단계가 바뀌어도 같은 URL
- 사이 간격 12
- **스크롤 고정** : 페이지를 스크롤해도 헤더 아래 24(위에서 88) 지점에 붙어서 따라오고, 푸터에 닿으면 멈춤 (sticky)

## 접힘 (퀵메뉴 버튼)
- 접으면 패널이 사라지고 본문은 1200 전체를 씀 (로그인 전 화면과 같은 배치)
- **본문 바깥 오른쪽 여백**에 작은 버튼이 생김
  - 위치 : 본문 오른쪽 끝에서 24 띄움, 펼침 패널과 같은 높이에 sticky (헤더 아래 24)
  - 크기 : 폭 72, `surface` 배경, `border` 테두리, 모서리 12, 안쪽 여백 12
  - 위에서부터 : 연결 상태 점(8px) → 송출 아이콘 `broadcast` 24 → "미리보기" (13px) → 아이콘 `chevron-left` 16 (아이콘은 design-rules.md "아이콘 (공통)")
  - 누르면 다시 펼침
- 오른쪽 여백이 버튼보다 좁은 화면(**1392 미만**, 본문 1248 + 24 + 72 + 여유) : 같은 버튼을 화면 오른쪽 아래 구석에 떠 있게 (오른쪽 24, 아래 24)
- **게임 진행 화면에서는 접기 없음** (항상 펼침, [미리보기 접기] 버튼도 숨김)

## 좁은 화면 (768 ~ 1279)
- 방송 패널은 카드 **위로** 쌓임 (design-rules.md 반응형 규칙)
- 패널 폭 : 본문 폭까지 넓어짐. 미리보기는 **576×324 그대로** 가운데 정렬 (0.3배 유지)
- sticky 없음. 스크롤하면 같이 올라감 (아래 카드를 가리지 않게)
- 접힘 퀵메뉴 버튼은 오른쪽 아래 구석에 떠 있는 버튼

## 펼침 / 접힘 기억
- 처음 로그인했을 때는 펼침
- 이후에는 마지막으로 고른 상태를 브라우저에 기억 (localStorage, 실패해도 펼침으로)

## 동작 (emit)
| 동작 | emit |
|---|---|
| [미리보기 접기] / 퀵메뉴 버튼 클릭 | `toggle` |
| [복사] 클릭 | `copy-url` |

- 복사가 끝나면 공통 토스트 "주소를 복사했어요" (부모가 처리)

## props
| 이름 | 타입 | 설명 |
|---|---|---|
| open | boolean | 펼침 여부 |
| overlayUrl | string | 표출 URL |
| connected | boolean | OBS 연결 여부 |
| collapsible | boolean | 접기 가능 여부 (게임 진행 화면은 false) |

## 나중에
- 연결 상태에 "브라우저에서 열림" 추가 : OBS 테스트(11/25)에서 OBS 구분이 되는지 확인 후

## 깨지기 쉬운 경우
- 긴 표출 URL
- 화면 높이가 낮을 때 (패널 높이 약 520 + 헤더 64 + 24)
- 접힘 버튼이 푸터와 겹치지 않는지
- 라이트 / 다크 모드
