# 딜레이 보정

- 와이어프레임: `../wireframes/delay.png`
  - 왼쪽 열: 조작 화면 모달, 오른쪽 열: 표출 화면(송출)
  - 위에서부터 #OBS 연결 → #1 → #2 → #3 → #4 → #5(성공 / 실패) → #6 → 저장 후
- 종류: 조작 화면 모달 + 표출 화면, 두 개를 짝으로 만든다
  - 조작 화면 모달: `src/components/DelayModal.vue` (공통 프레임의 AppModal 안에 들어감)
  - 표출 화면: `src/components/overlay/DelayOverlay.vue` (표출 페이지 안에서 딜레이 측정 중일 때 보여주는 조각, 1920×1080)
- 헤더의 [딜레이 보정] 버튼을 누르면 모달이 열림

## 핵심 규칙
- 신호(회색 박스 → 주황 박스)는 **표출 화면에만** 나온다. 조작 화면 모달에는 신호를 보여주지 않는다
  - 스트리머는 치지직 방송 페이지에서 신호를 보고 모달의 [보였어요]를 누른다
- 그래서 모달의 #3과 #4는 같은 화면이다

## 단계별 화면

| 단계 | 조작 화면 (모달) | 표출 화면 (송출) |
|---|---|---|
| #OBS 연결 (연결 안 됐을 때만) | 제목 "딜레이 보정" / "OBS에 위마당 화면을 먼저 넣어주세요." / 표출 URL + [복사] / "연결을 기다리는 중..." / [취소] | (아직 없음) |
| #1 안내 | 제목 "딜레이 보정" / 안내 문구 / [취소] [측정] | 대기 화면 |
| #2 카운트다운 | "딜레이 보정 1/3" / "방송 화면을 봐주세요." | 큰 숫자 3 → 2 → 1 / "딜레이 측정 중" |
| #3 대기 | "딜레이 보정 1/3" / "방송화면에서 주황색이 되면 아래 버튼을 클릭해주세요." / [보였어요] | 회색 박스 "곧 신호가 뜹니다." / "딜레이 측정 중" |
| #4 신호 | #3과 같음 | 주황 박스 "지금!" / "딜레이 측정 중" |
| #5 성공 | 초록 "1/3 완료 (3.2초)" / [보였어요] | 회색 박스 (다음 회차) |
| #5 실패 | 빨강 "너무 빨라요, 다시할게요." 또는 "15초 초과, 다시할게요." / [보였어요] | 회색 박스 (같은 회차 다시) |
| #6 결과 | 초록 "딜레이 3.2초" / 3.1 3.3 3.2 / 입력칸 [3.2] 초 / [다시] [취소] [저장] | 초록 "딜레이 3.2초" / 3.1 3.3 3.2 |
| 저장 후 | 모달 닫힘, 보던 화면으로 돌아감 / 토스트 "딜레이 3.2초로 저장했어요" | 대기 화면 |

- #2 ~ #5는 3회 반복 (1/3 → 2/3 → 3/3)
- 대기 박스 색은 `signal-wait`, 신호 박스 색은 `signal-on`, 박스 위 글자는 `on-signal` (design-rules.md)

## 동작 (emit) — 조작 화면 모달
| 동작 | emit |
|---|---|
| [취소] | `cancel` |
| [복사] (표출 URL) | `copy-url` |
| [측정] | `start` |
| [보였어요] | `seen` |
| [다시] | `retry` |
| 결과 숫자 직접 수정 | `update:result` (숫자) |
| [저장] | `save` |

## props — 조작 화면 모달
| 이름 | 타입 | 설명 |
|---|---|---|
| step | 'connect' \| 'intro' \| 'countdown' \| 'waiting' \| 'success' \| 'fail' \| 'result' | 지금 단계 |
| round | number | 회차 (1 ~ 3) |
| lastSeconds | number | 방금 회차 결과 (성공일 때) |
| failReason | 'too-early' \| 'timeout' | 실패 이유 |
| values | number[] | 3회 측정값 |
| result | number | 평균 (소수점 한 자리), 수정 가능 |
| overlayUrl | string | 표출 URL |

## props — 표출 화면 조각
| 이름 | 타입 | 설명 |
|---|---|---|
| phase | 'countdown' \| 'waiting' \| 'signal' \| 'result' | 지금 단계 |
| count | number | 카운트다운 숫자 (3, 2, 1) |
| values | number[] | 결과 단계의 3회 측정값 |
| result | number | 결과 단계의 평균 |

## 정할 것
- #6 표출 화면 결과를 몇 초 보여주고 대기 화면으로 돌아갈지

## 깨지기 쉬운 경우
- 측정값이 0.3초처럼 작거나 14.9초처럼 클 때
- 결과 입력칸에 소수점 두 자리 이상을 넣을 때
- 표출 URL이 길 때
- 좁은 너비 (768 ~ 1279)에서 모달
